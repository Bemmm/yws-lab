Создай MVP веб-приложения YWSLab Progress System.

Это внутренняя система для кураторов и менторов YWS Lab, которая фиксирует стартовый профиль студентов и отслеживает развитие их компетенций по ходу курса в формате RPG-прокачки навыков.

## Главная идея

Нужно не приложение для выставления оценок, а система визуализации прогресса студента.

У каждого студента есть:

1. Стартовый профиль.
2. Компетенции.
3. Точка 0.
4. Контрольные точки по ходу курса.
5. Финальная точка.
6. Динамика развития по каждой компетенции.

## Стартовые профили

Сделай выбор одного из трех профилей:

### 1. Огранка

* Уже способен проводить тренировку по системе.
* Понимает режим и его принципы.
* Требуется довести исполнение до профессионального уровня и/или повысить компетентность.

### 2. Перепрошивка

* Умеет проводить тренировку, но не по системе YWS.
* Работает на основе собственного опыта, представлений и интуиции.
* Требуется перестройка структуры проведения.

### 3. Не умеет проводить тренировку

* Навык проведения тренировки отсутствует.
* Требуется формирование навыка с нуля.

## Группы компетенций

### I. Базовые профессиональные компетенции

* Владение речью и голосом.
* Функция ретранслятора.
* Уверенность.
* Контакт с аудиторией.
* Физическая подготовка.
* Координация.
* Способность демонстрировать упражнения.
* Чувство ритма.
* Пластика движений.

### II. Системные компетенции YWS

* Понимание и владение режимом.
* Своевременность команд.
* Качество команд.
* Управление вниманием группы.
* Понимание задач упражнения.
* Работа с переходами.
* Соблюдение принципов системы.

## Система оценки

Для каждой компетенции используется шкала от 0 до 10.

Нужно фиксировать значения на этапах:

* Точка 0
* Модуль 1
* Модуль 2
* Модуль 3
* Финал

Количество модулей должно быть легко изменить в коде.

## Основные экраны

### 1. Главный экран группы

Показывает всех студентов карточками.

На карточке студента должно быть:

* имя;
* стартовый профиль;
* общий текущий уровень;
* общий прирост с точки 0;
* статус динамики;
* краткая RPG-визуализация навыков.

Статусы:

* Устойчивый рост
* Резкий рост
* Стагнация
* Зона внимания

### 2. Карточка студента

Показывает подробную информацию:

* имя студента;
* стартовый профиль;
* текущая контрольная точка;
* две группы компетенций;
* каждая компетенция отображается как RPG skill bar;
* рядом с каждой компетенцией показывать текущее значение и изменение относительно точки 0;
* отдельно показывать изменение относительно предыдущей контрольной точки.

Пример визуализации:

Режим
██████░░░░ 6/10
+3 от точки 0
+1 от прошлого этапа

### 3. Экран ввода оценки

Нужно иметь возможность выбрать:

* студента;
* контрольную точку;
* компетенцию;
* значение от 0 до 10.

Можно использовать слайдеры или числовой ввод.

Нужна кнопка “Сохранить”.

На MVP данные можно хранить в localStorage.

### 4. Экран сравнения динамики

Показывает прогресс студента по всем контрольным точкам.

Например:

Точка 0 → Модуль 1 → Модуль 2 → Модуль 3 → Финал

Для каждой компетенции показать мини-график или горизонтальную историю значений.

## Визуальный стиль

Стиль: современный внутренний дашборд, немного RPG, но без детскости.

Нужно ощущение:

* профессиональная методическая система;
* карта развития навыков;
* внутренняя панель куратора.

Цвета:

* темный фон;
* акцентные цвета для групп компетенций;
* зеленый для роста;
* желтый для стагнации;
* красный для зоны внимания;
* фиолетовый/синий для системных компетенций YWS.

## Важные требования

* Не делать рейтинг студентов.
* Не сортировать по принципу “кто лучший”.
* Главный фокус — динамика развития.
* Сравнение должно быть относительно точки 0 и предыдущего этапа.
* Интерфейс должен быть понятен кураторам без технической подготовки.
* Приложение должно быть адаптивным для ноутбука и планшета.
* Код должен быть простым и понятным.

## Технически

Сделай приложение на React.

Можно использовать:

* React
* TypeScript
* Tailwind CSS
* localStorage для MVP
* без backend на первом этапе


Структура данных должна быть подготовлена так, чтобы позже можно было заменить localStorage на базу данных.

Создай демо-данные для 5 студентов с разными стартовыми профилями и разной динамикой прогресса.

## Что должно получиться

Рабочий MVP, где куратор может:

1. Добавить или выбрать студента.
2. Назначить стартовый профиль.
3. Внести оценки по компетенциям в точке 0.
4. Внести оценки после модулей.
5. Видеть RPG-прокачку навыков.
6. Видеть прирост по каждой компетенции.
7. Видеть общую динамику студента.
8. Видеть общую картину группы.
