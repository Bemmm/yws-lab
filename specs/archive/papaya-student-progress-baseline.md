## 1. Контекст

### 1.1 Актор и цель

**Кто:** тренер, который ведёт курс подготовки тренеров по системе YWS. Его ученики — будущие тренеры.
**Цель:** зафиксировать, с чем каждый ученик пришёл на курс, и по ходу курса видеть, как растёт каждая его компетенция — относительно точки 0 и относительно прошлого этапа. Продукт показывает развитие ученика, а не сравнивает учеников между собой.

### 1.2 Что такое курс и этапы

| Понятие | Что означает |
|---|---|
| **курс** | обучение группы будущих тренеров по системе YWS: название, число модулей, список учеников |
| **ученик курса** | ученик из базы тренера (PAP-2 · База учеников, 1.2), добавленный в курс; у него есть стартовый профиль и оценки |
| **этап** | момент, в который тренер оценивает ученика: **Точка 0**, **Модуль 1** … **Модуль N**, **Финал** |
| **оценка** | целое число от 0 до 10 по одной компетенции на одном этапе. 0 — оценка, а не пропуск; компетенция без оценки — «не оценено» |
| **уровень** | среднее оценок ученика на этапе — общий и по каждой группе компетенций (см. 4.1) |
| **динамика** | словесная метка того, как ученик меняется между двумя последними заполненными этапами (см. 4.3) |

Этапы курса идут в фиксированном порядке: **Точка 0** → **Модуль 1** → … → **Модуль N** → **Финал**. Число модулей задаёт тренер (см. 2.2). **Точка 0** — оценка на входе в курс, **Финал** — на выходе.

Один ученик может быть в нескольких курсах; оценки каждого курса независимы.

### 1.3 Компетенции

Шестнадцать компетенций в двух группах — константа продукта. Тренер их не меняет, не добавляет и не убирает. Порядок на всех экранах — как в таблице.

| Группа | Компетенции |
|---|---|
| **I. Базовые профессиональные** | Владение речью и голосом · Функция ретранслятора · Уверенность · Контакт с аудиторией · Физическая подготовка · Координация · Способность демонстрировать упражнения · Чувство ритма · Пластика движений |
| **II. Системные компетенции YWS** | Понимание и владение режимом · Своевременность команд · Качество команд · Управление вниманием группы · Понимание задач упражнения · Работа с переходами · Соблюдение принципов системы |

На карточке курса, в таблице динамики и на узком экране компетенции подписаны коротко; полное название всегда доступно в подсказке.

| Компетенция | Коротко |
|---|---|
| Владение речью и голосом | Речь и голос |
| Функция ретранслятора | Ретранслятор |
| Уверенность | Уверенность |
| Контакт с аудиторией | Контакт |
| Физическая подготовка | Физподготовка |
| Координация | Координация |
| Способность демонстрировать упражнения | Демонстрация |
| Чувство ритма | Ритм |
| Пластика движений | Пластика |
| Понимание и владение режимом | Режим |
| Своевременность команд | Своевременность |
| Качество команд | Качество команд |
| Управление вниманием группы | Внимание группы |
| Понимание задач упражнения | Задачи упражнения |
| Работа с переходами | Переходы |
| Соблюдение принципов системы | Принципы системы |

Компетенции хранятся кодами, а названия берутся из перевода. Набор компетенций можно расширить в следующей версии, не трогая сохранённые оценки (см. 9.2).

### 1.4 Стартовые профили

Тренер присваивает ученику один стартовый профиль, когда добавляет его в курс. Профиль описывает, с чем ученик пришёл, и не влияет на расчёты (см. 4).

| Профиль | Описание на экране |
|---|---|
| **Огранка** | «Уже проводит занятие по системе и понимает режим и его принципы. Нужно довести исполнение до профессионального уровня» |
| **Перепрошивка** | «Проводит занятия, но не по системе YWS — на собственном опыте и интуиции. Нужно перестроить структуру проведения» |
| **С нуля** | «Пока не умеет проводить занятие. Навык формируется с нуля» |

Профиль можно сменить в любой момент из прогресса ученика (см. 6.1). Оценки при смене профиля не меняются.

### 1.5 Зависимости

| Задача | Что даёт этой |
|---|---|
| PAP-1 · Регистрация тренера | кабинет тренера и его разделы, общие правила форм, язык интерфейса |
| PAP-2 · База учеников | ученики, из которых набирается курс; архив и удаление карточки; поиск по имени, email и телефону |

Подтверждение адреса тренера на работу с курсами не влияет: ученик ничего не получает, все действия остаются внутри кабинета тренера.

## 2. Основной процесс

### 2.1 Основной сценарий

1. Тренер открывает раздел **Курсы** и нажимает **Новый курс**. Указывает название и число модулей (см. 2.2), нажимает **Создать курс**. Открывается экран курса (см. 5) — пока без учеников.
2. Нажимает **Добавить ученика**, выбирает учеников из своей базы и каждому выбирает стартовый профиль (см. 2.3).
3. На карточке ученика нажимает **Оценить** — открывается форма оценки на этапе **Точка 0** (см. 3.1). Тренер ставит оценки по компетенциям и нажимает **Сохранить**.
4. После каждого модуля тренер открывает форму на этапе этого модуля и ставит новые оценки. В конце курса — на этапе **Финал**.
5. На экране курса тренер видит всех учеников с уровнем, приростом от точки 0 и динамикой (см. 5.1) и картину группы (см. 5.2).
6. Открывает прогресс ученика: шкалы компетенций с изменением от точки 0 и от прошлого этапа (см. 6.1) и историю значений по всем этапам (см. 6.2).

### 2.2 Поля курса

Правила форм общие (PAP-1 · Регистрация тренера, 2.2).

| Поле | Обязательное | Правила | Сообщение при ошибке |
|---|---|---|---|
| Название курса | да | 1–80 символов | «Введите название курса» |
| Число модулей | да | целое от 1 до 12; при первом открытии — 3 | «Модулей — от 1 до 12» |

Пределы — константы продукта; число модулей при первом открытии — поле формы. Те же поля правятся кнопкой **Настройки курса** на экране курса.

Число модулей можно увеличить в любой момент: новые модули встают перед **Финалом**, уже поставленные оценки не меняются. Уменьшить можно только до последнего модуля, в котором есть хотя бы одна оценка: «В модуле ‹N› уже есть оценки — модулей не может быть меньше ‹N›».

**Удалить курс** в **Настройках курса** спрашивает подтверждение «Удалить курс „‹название›“? Оценки всех учеников курса будут удалены без возможности восстановления.» с действиями **Отмена** и **Удалить**. Карточки учеников в базе остаются.

### 2.3 Ученики курса

**Добавить ученика** открывает выбор из базы тренера с поиском по имени, email и телефону — как в списке учеников (PAP-2 · База учеников, 4.3). Тренер отмечает одного или нескольких.

| Ученик в базе | В выборе |
|---|---|
| активный — с аккаунтом, без аккаунта или приглашённый | можно выбрать: аккаунт для курса не нужен, ученик ничего не получает |
| в архиве | не показан |
| уже в этом курсе | показан неактивным с пометкой «Уже в курсе» |

После выбора тренер для каждого отмеченного ученика выбирает стартовый профиль (см. 1.4). Поле обязательное, при первом открытии не выбрано: «Выберите стартовый профиль». Кнопка **Добавить** добавляет всех отмеченных сразу.

В курсе — до 50 учеников, константа продукта. При пятидесяти **Добавить ученика** неактивна с подсказкой «В курсе не больше 50 учеников».

Если нужного человека в базе нет, тренер заводит его в разделе **Ученики** (PAP-2 · База учеников, 3.1); в выборе есть ссылка **Завести нового ученика**, которая ведёт туда.

**Убрать из курса** — в меню карточки ученика на экране курса. Подтверждение: «Убрать ‹имя› из курса? Все его оценки в этом курсе будут удалены.» с действиями **Отмена** и **Убрать**. Карточка в базе остаётся.

Что происходит с учеником курса при изменениях в базе:

| В базе | В курсе |
|---|---|
| карточка ушла в архив (PAP-2 · База учеников, 6.2) | ученик остаётся в курсе с пометкой «В архиве»; оценки и правка оценок доступны |
| карточка вернулась из архива | пометка снимается |
| карточка удалена (PAP-2 · База учеников, 6.3) | ученик и все его оценки удаляются из всех курсов |
| ученик сменил имя в профиле | в курсе показано текущее имя по PAP-2 · База учеников, 2.4 |

## 3. Оценка этапа

Тренер оценивает ученика сразу по всем шестнадцати компетенциям на одном этапе — так же, как он смотрит на ученика после модуля целиком. Ставить все оценки за один раз не обязательно: можно вернуться и дополнить.

### 3.1 Форма оценки

Форма открывается кнопкой **Оценить** на карточке ученика или в прогрессе ученика.

| Элемент | Что в нём |
|---|---|
| **Ученик** | имя; переключатель на другого ученика этого курса без закрытия формы |
| **Этап** | выбор этапа курса. При открытии выбран первый незаполненный этап (см. 4.1); все этапы заполнены — **Финал** |
| Компетенции | две группы по 1.3. У каждой компетенции — шкала-слайдер 0–10 с шагом 1 и поле числа рядом; слайдер и поле связаны |
| Подсказка у компетенции | оценка этой компетенции на прошлом этапе: «Было: ‹N› на этапе ‹этап›»; оценки раньше нет — подсказки нет |
| Счётчик | «Оценено ‹K› из 16» над кнопками |
| Кнопки | **Сохранить**, **Отмена** |

Компетенция без оценки показывается как «не оценено»: слайдер без отметки, поле пустое. Поставленную оценку можно убрать кнопкой **Очистить** у компетенции — компетенция снова «не оценено».

Слайдер и поле числа работают с клавиатуры: стрелки меняют оценку на 1, Home и End ставят 0 и 10.

| Поле | Обязательное | Правила | Сообщение при ошибке |
|---|---|---|---|
| Оценка компетенции | нет | целое число от 0 до 10 | «Оценка — целое число от 0 до 10» |

### 3.2 Порядок этапов

Этап доступен для оценки, когда на предыдущем этапе есть хотя бы одна оценка. **Точка 0** доступна всегда. Недоступные этапы в выборе неактивны с подсказкой «Сначала поставьте оценки на этапе ‹этап›».

Оценки на любом этапе, на котором они уже есть, тренер правит в любой момент. Если после правки на предыдущем этапе не осталось ни одной оценки, последующие этапы с оценками не блокируются и остаются доступными.

### 3.3 Сохранение

**Сохранить** записывает все изменения формы одним действием и показывает «Оценки сохранены». Форма закрывается, открывается то место, откуда тренер её открыл.

Переключение ученика или этапа с несохранёнными изменениями спрашивает: «Сохранить оценки этапа ‹этап›?» с действиями **Сохранить**, **Не сохранять** и **Отмена**. Уход из формы с несохранёнными изменениями — тот же вопрос.

Курс можно открыть в двух вкладках или на двух устройствах. Сохранение из окна, где оценки этапа устарели, не затирает более новые: форма показывает «Оценки этого этапа изменены в другом окне — показаны последние» и подгружает их, а изменения этого окна по тем же компетенциям не сохраняются.

## 4. Расчёты

Все расчёты в этом разделе — константы продукта, тренер их не настраивает. Значения округляются до одного знака после запятой при показе, расчёты идут по неокруглённым.

### 4.1 Заполненный этап и уровень

**Этап заполнен**, когда на нём оценены все 16 компетенций. Уровень и динамика считаются только по заполненным этапам; на незаполненном этапе показывается «Оценено ‹K› из 16».

| Показатель | Как считается |
|---|---|
| **Уровень на этапе** | среднее всех 16 оценок заполненного этапа, 0–10 |
| **Уровень группы компетенций** | среднее оценок группы на заполненном этапе: базовые — 9 оценок, системные — 7 |
| **Текущий уровень** | уровень на последнем заполненном этапе |
| **Прирост от точки 0** | текущий уровень минус уровень на **Точке 0**; есть, только если **Точка 0** заполнена и после неё заполнен хотя бы один этап |
| **Текущий этап** | последний этап, на котором есть хотя бы одна оценка |

### 4.2 Изменение компетенции

Для каждой компетенции отдельно:

| Показатель | Как считается |
|---|---|
| **Текущее значение** | оценка на последнем этапе, где эта компетенция оценена |
| **От точки 0** | текущее значение минус оценка на **Точке 0**; оценки на **Точке 0** нет — показатель не показывается |
| **От прошлого этапа** | текущее значение минус оценка на ближайшем более раннем этапе, где эта компетенция оценена; такого этапа нет — показатель не показывается |

Изменение пишется со знаком: «+3», «0», «−1». Рост — зелёным, ноль — нейтральным цветом, снижение — красным.

### 4.3 Динамика

Динамика считается по двум последним заполненным этапам: Δ — уровень на последнем минус уровень на предпоследнем. Правила проверяются сверху вниз, срабатывает первое подходящее.

| # | Условие | Метка | Цвет |
|---|---|---|---|
| 1 | **Точка 0** не заполнена | «Точка 0 не заполнена» | серый |
| 2 | заполнен только один этап | «Пока только точка 0» | серый |
| 3 | Δ < 0 или хотя бы одна компетенция снизилась на 2 и больше между этими этапами | «Зона внимания» | красный |
| 4 | 0 ≤ Δ < 0,3 | «Стагнация» | жёлтый |
| 5 | 0,3 ≤ Δ < 1,5 | «Устойчивый рост» | зелёный |
| 6 | Δ ≥ 1,5 | «Резкий рост» | зелёный, отдельный значок |

| Параметр | Значение | Чьё |
|---|---|---|
| Порог стагнации | 0,3 | константа продукта |
| Порог резкого роста | 1,5 | константа продукта |
| Снижение компетенции для зоны внимания | 2 | константа продукта |

У метки «Зона внимания» — одна причина строкой. Снизился уровень — «Уровень снизился на ‹Δ›». Иначе — «‹компетенция›: ‹изменение›» по первой снизившейся компетенции в порядке 1.3, а при нескольких таких — с добавкой «и ещё ‹N›».

## 5. Экран курса

Экран курса — главный экран раздела: вся группа на одном экране, чтобы тренер видел, кто как развивается, не открывая каждого.

### 5.1 Карточка ученика в курсе

| Что на карточке | Как показано |
|---|---|
| Имя | как в базе; пометка «В архиве», если карточка в архиве |
| Стартовый профиль | метка профиля по 1.4 |
| Текущий уровень | «‹уровень› / 10» и текущий этап; нет заполненных этапов — «Нет уровня» |
| Прирост от точки 0 | «+‹N› от точки 0»; нет данных — не показывается |
| Динамика | метка и цвет по 4.3; у «Зоны внимания» — причина |
| Шкалы групп | две шкалы на 10 делений: уровень базовых и уровень системных компетенций на последнем заполненном этапе, каждая в цвете своей группы |
| Действия | **Оценить** (см. 3.1); меню: **Открыть прогресс**, **Динамика**, **Убрать из курса** |

Нажатие на карточку открывает прогресс ученика (см. 6.1).

Цвета групп: базовые профессиональные — бирюзовый, системные компетенции YWS — фиолетово-синий. Окончательные оттенки задаются при отрисовке макетов.

### 5.2 Картина группы

Над карточками — сводка по курсу:

| Блок | Что показывает |
|---|---|
| Динамика группы | сколько учеников с каждой меткой из 4.3: «Устойчивый рост: 2 · Резкий рост: 1 · Стагнация: 1 · Зона внимания: 1» |
| Компетенции группы | по каждой из 16 компетенций — средний прирост от точки 0 у учеников, у которых он есть, и число этих учеников: «Режим +2,4 · 5 учеников». Порядок — по 1.3 |
| Этапы | сколько учеников заполнили каждый этап: «Точка 0: 5 из 5 · Модуль 1: 5 из 5 · Модуль 2: 3 из 5» |

Нажатие на метку в блоке «Динамика группы» отбирает карточки с этой меткой (см. 5.3).

### 5.3 Порядок и отбор

Карточки идут по имени в алфавитном порядке — константа продукта. Сортировки по уровню, приросту или динамике нет, номеров мест нет.

Отбор — по стартовому профилю и по метке динамики; при первом открытии отбора нет. Отбор меняет только видимые карточки, сводка в 5.2 всегда считается по всему курсу.

Пустой курс показывает «В курсе пока нет учеников» и кнопку **Добавить ученика**. Отбор, под который никто не подходит, — «Под отбор никто не подходит» и **Сбросить отбор**.

## 6. Прогресс ученика

### 6.1 Шкалы компетенций

Экран прогресса ученика в курсе.

| Блок | Что в нём |
|---|---|
| Шапка | имя, стартовый профиль с действием **Сменить профиль**, текущий этап, текущий уровень, прирост от точки 0, динамика по 4.3 |
| Две группы | заголовок группы с её уровнем; под ним шкалы компетенций группы в порядке 1.3 |
| Действия | **Оценить** (см. 3.1), **Динамика** (см. 6.2) |

Шкала компетенции — полоса из 10 делений, закрашено столько, сколько стоит текущее значение, в цвете группы. Рядом — значение и две строки изменения по 4.2:

```
Понимание и владение режимом
██████░░░░  6/10
+3 от точки 0
+1 от прошлого этапа
```

Компетенция без единой оценки показывает пустую полосу и «не оценено». Изменение, которого нет по 4.2, не показывается.

**Сменить профиль** открывает выбор из трёх профилей с описаниями по 1.4 и кнопкой **Сохранить**.

### 6.2 Экран динамики

Экран показывает путь ученика по всем этапам курса: **Точка 0** → **Модуль 1** → … → **Финал**.

| Строка | Что в ней |
|---|---|
| Общий уровень | уровень на каждом заполненном этапе; на незаполненном — «‹K› из 16» |
| Уровень групп | по строке на группу: уровень группы на каждом заполненном этапе |
| Компетенция | по строке на каждую из 16 компетенций: оценка на каждом этапе и мини-график значений по этапам |

Колонки — этапы курса по порядку, включая ещё не оценённые. Между соседними значениями в строке показано изменение по цвету из 4.2. Пустая клетка — «—».

Мини-график — линия по оценкам этапов, где компетенция оценена; ось 0–10 одна для всех строк, чтобы графики можно было сравнивать на глаз.

## 7. Нефункциональные требования

| Свойство | Требование |
|---|---|
| **Приватность** | курсы, профили и оценки видит только тренер — владелец курса. Ученик свои оценки не видит и о курсе не уведомляется. Удаление карточки ученика удаляет его оценки (см. 2.3) |
| **Безопасность** | каждое чтение и изменение проверяет на сервере, что курс принадлежит тренеру. Оценка вне 0–10 или не целая, неизвестная компетенция и недоступный этап (см. 3.2) отклоняются сервером независимо от браузера |
| **Наблюдаемость** | ошибки сохранения оценок и конфликты двух окон (см. 3.3) пишутся в журнал ошибок без самих оценок и имён |
| **Надёжность** | сохранение этапа целиком проходит или целиком не проходит; при обрыве связи набранное остаётся в форме, показывается «Не удалось сохранить. Проверьте соединение и нажмите «Сохранить» ещё раз» |
| **Доступность** | цвет — не единственный признак: у динамики всегда есть метка, у изменения — знак, у шкалы — число. Слайдеры управляются с клавиатуры (см. 3.1), у шкал есть текстовое значение для экранного диктора |
| **Узкий экран** | основная ширина — ноутбук и планшет от 768 px: карточки курса в 2–3 колонки. На телефоне карточки в одну колонку, форма оценки — по одной компетенции в строке, таблица динамики прокручивается по горизонтали с закреплённой колонкой названий |
| **Локализация** | названия компетенций, профилей, этапов и меток динамики — на трёх языках интерфейса; дробная часть уровня — по правилам языка: «6,4» / «6.4» |
| **Производительность** | экран курса на 50 учеников со всеми этапами открывается не дольше 2 секунд; расчёты по 4 выполняет сервер |
| **Масштабируемость** | до 50 учеников в курсе (см. 2.3), до 14 этапов (12 модулей, точка 0 и финал), 16 компетенций — до 11 200 оценок в курсе |
| **Совместимость** | N/A — те же браузеры, что у всего кабинета тренера по PAP-1 · Регистрация тренера |

## 8. Альтернативы и ошибки

| Ситуация | Поведение | Где описано |
|---|---|---|
| Тренер уходит из формы с несохранёнными оценками | вопрос «Сохранить оценки этапа ‹этап›?» | 3.3 |
| Оценки этапа изменены в другом окне | показываются последние, изменения этого окна по тем же компетенциям не сохраняются | 3.3 |
| Связь оборвалась при сохранении | набранное остаётся, сообщение об ошибке | 7, **Надёжность** |
| Тренер выбирает этап, у предыдущего нет оценок | этап неактивен с подсказкой | 3.2 |
| Тренер уменьшает число модулей ниже оценённого модуля | сообщение, число модулей не меняется | 2.2 |
| В курсе 50 учеников | **Добавить ученика** неактивна | 2.3 |
| Карточка ученика ушла в архив | ученик остаётся в курсе с пометкой | 2.3 |
| Карточка ученика удалена | ученик и его оценки удалены из курсов | 2.3 |
| Этап заполнен частично | уровень и динамика его не учитывают, показано «Оценено ‹K› из 16» | 4.1 |
| Нет оценки на точке 0 по компетенции | изменение «от точки 0» не показывается | 4.2 |
| Курс открыт по ссылке другим тренером | «Курс не найден» — существование чужого курса не раскрывается | 7, **Безопасность** |

## 9. Границы MVP

### 9.1 Что входит

- раздел **Курсы**: создание, правка и удаление курса с числом модулей 1–12;
- ученики курса из базы тренера, стартовый профиль, смена профиля;
- оценка 16 компетенций по шкале 0–10 на этапах **Точка 0**, **Модуль 1…N**, **Финал**, частичное заполнение;
- уровень, прирост от точки 0, изменение от прошлого этапа, динамика по 4.3;
- экран курса со сводкой группы, прогресс ученика, экран динамики;
- проверочный набор из пяти учеников на стенде (см. 11.6).

### 9.2 Что не входит

| Что | Причина |
|---|---|
| Рейтинг, сортировка по уровню, «лучший ученик» | продукт показывает развитие ученика относительно себя, а не соревнование |
| Несколько тренеров оценивают одних учеников в одном курсе | база учеников принадлежит одному тренеру (PAP-2 · База учеников, 1.2); совместная работа появится вместе со школой |
| Ученик видит свои оценки | методика сначала обкатывается как внутренний инструмент тренера; открытие ученику требует отдельных текстов и правил |
| Свой набор компетенций, свои группы, свои профили | набор утверждён методикой YWS; модель хранит компетенции кодами, расширение не потребует переноса оценок |
| Комментарий к оценке или этапу | не запрошено; приватная заметка в карточке ученика остаётся (PAP-2 · База учеников, 5.3) |
| История правок оценок | в MVP один оценивающий; при появлении нескольких тренеров понадобится вместе с ними |
| Экспорт и печать прогресса | не запрошено |
| Хранение в браузере (localStorage) | оценки хранятся на сервере, как все данные кабинета; иначе они пропадут при смене устройства |
| Тёмная тема только для раздела **Курсы** | раздел оформляется в общей теме кабинета, как остальные разделы; цвета групп и меток динамики (см. 4.3, 5.1) читаются и на светлом фоне. Тёмная тема, если появится, — для всего кабинета сразу |

### 9.3 Влияние на соседние задачи

| Задача | Что меняется |
|---|---|
| PAP-1 · Регистрация тренера | в кабинете тренера появляется раздел **Курсы** |
| PAP-2 · База учеников | в карточке ученика — блок **Курсы**: названия курсов, где он есть, со ссылкой на его прогресс; удаление карточки удаляет его оценки (см. 2.3); подтверждение удаления дополняется строкой «Оценки ученика в курсах тоже будут удалены», если ученик есть хотя бы в одном курсе |

## 10. Экраны

1. **Курсы** — список курсов тренера: название, число учеников, этапы; пустое состояние «У вас пока нет курсов» с **Новый курс**.
2. **Новый курс / Настройки курса** — форма по 2.2; в настройках — **Удалить курс** с подтверждением.
3. **Экран курса** — сводка группы (5.2), отбор (5.3), карточки учеников (5.1); состояния: пустой курс, пустой отбор.
4. **Добавить ученика в курс** — выбор из базы с поиском и выбором профиля для каждого (2.3); состояния: база пуста, все уже в курсе, лимит 50.
5. **Форма оценки** — ученик, этап, 16 компетенций со слайдерами (3.1); состояния: этап пустой, частично заполнен, заполнен; несохранённые изменения; конфликт двух окон; ошибка сохранения.
6. **Прогресс ученика** — шапка и шкалы компетенций по группам (6.1); состояния: нет оценок, только точка 0, несколько этапов; диалог **Сменить профиль**.
7. **Динамика** — таблица этапов и компетенций с мини-графиками (6.2); на телефоне — горизонтальная прокрутка.
8. **Блок «Курсы» в карточке ученика** — дополнение экрана PAP-2 · База учеников (9.3).

## 11. Критерии приёмки

### 11.1 Курс и ученики

- [ ] Тренер создаёт курс с названием и числом модулей; при первом открытии формы число модулей — 3.
- [ ] Число модулей 0 или 13 не сохраняется, показано «Модулей — от 1 до 12».
- [ ] Курс с оценками в модуле 3 нельзя сократить до 2 модулей; показано «В модуле 3 уже есть оценки — модулей не может быть меньше 3».
- [ ] Увеличение числа модулей добавляет модули перед **Финалом**, оценки **Финала** сохраняются.
- [ ] В выборе учеников есть активные ученики без аккаунта; архивных нет; уже добавленные неактивны с пометкой «Уже в курсе».
- [ ] Ученик не добавляется в курс без стартового профиля.
- [ ] 51-й ученик не добавляется: кнопка неактивна с подсказкой «В курсе не больше 50 учеников».
- [ ] **Убрать из курса** после подтверждения удаляет оценки ученика в этом курсе; карточка в базе остаётся.
- [ ] Удаление карточки ученика в базе убирает его из всех курсов вместе с оценками.
- [ ] Архивация карточки оставляет ученика в курсе с пометкой «В архиве».
- [ ] Смена стартового профиля не меняет ни одной оценки и ни одного расчёта.

### 11.2 Оценка этапа

- [ ] Форма открывается на первом незаполненном этапе.
- [ ] Слайдер и поле числа одной компетенции показывают одно значение; ввод 11 или 5,5 не сохраняется с сообщением «Оценка — целое число от 0 до 10».
- [ ] Оценка 0 сохраняется и отличается от «не оценено» на всех экранах.
- [ ] Сохранение 9 оценок из 16 проходит; этап показывает «Оценено 9 из 16».
- [ ] **Модуль 2** неактивен, пока на **Модуле 1** нет ни одной оценки.
- [ ] Уход из формы с несохранёнными изменениями спрашивает «Сохранить оценки этапа ‹этап›?».
- [ ] Сохранение из второго окна с устаревшими оценками не затирает оценки, сохранённые в первом.
- [ ] Сервер отклоняет оценку вне 0–10 и оценку на недоступном этапе, отправленные в обход формы.

### 11.3 Расчёты и динамика

- [ ] Уровень этапа равен среднему 16 оценок; частично заполненный этап в уровень не входит.
- [ ] Прирост от точки 0 равен текущему уровню минус уровень на **Точке 0**.
- [ ] Компетенция с оценками 3 на **Точке 0**, 5 на **Модуле 1**, 6 на **Модуле 2** показывает «6/10», «+3 от точки 0», «+1 от прошлого этапа».
- [ ] Компетенция, не оценённая на **Модуле 1**, считает «от прошлого этапа» от **Точки 0**.
- [ ] Каждая метка из 4.3 появляется ровно при своём условии; Δ = 0,3 даёт «Устойчивый рост», Δ = 1,5 — «Резкий рост».
- [ ] Рост уровня на 0,5 при падении одной компетенции на 2 даёт «Зону внимания» с причиной «‹компетенция›: −2».

### 11.4 Экраны прогресса

- [ ] Карточки курса идут по алфавиту; на экране курса нет сортировки по уровню, приросту или динамике.
- [ ] Отбор по метке меняет карточки, но не сводку группы.
- [ ] Сводка «Динамика группы» совпадает с метками на карточках.
- [ ] Прогресс ученика показывает 9 шкал базовых и 7 шкал системных компетенций в порядке 1.3, каждая в цвете группы.
- [ ] Экран динамики показывает колонку на каждый этап курса, включая неоценённые, с «—» в пустых клетках.
- [ ] Мини-графики всех компетенций построены на одной оси 0–10.

### 11.5 Приватность и узкий экран

- [ ] Другой тренер по прямой ссылке на курс видит «Курс не найден».
- [ ] Ученик с аккаунтом не видит в своём кабинете ни курса, ни оценок и не получает уведомлений.
- [ ] На планшете 768 px экран курса, форма оценки и прогресс помещаются без горизонтальной прокрутки страницы.
- [ ] На телефоне 375 px таблица динамики прокручивается по горизонтали, колонка названий закреплена.
- [ ] Метка динамики, знак изменения и число на шкале читаются без опоры на цвет.

### 11.6 Проверочный набор на стенде

На стенде у проверочного тренера заводится курс «Подготовка тренеров YWS · проверка» с тремя модулями и пятью учениками. Заполнены **Точка 0**, **Модуль 1** и **Модуль 2**; **Модуль 3** и **Финал** пусты. Набор не попадает в прод.

| Ученик | Профиль | Уровень: точка 0 → модуль 1 → модуль 2 | Что проверяет |
